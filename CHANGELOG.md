# Changelog

All notable changes to this project are documented in this file.

## 2.0.0 - 2026-11-19

### Added

- Fabric-ready UniList v2 API with tuned virtualized windowing, skeleton loading, swipe actions, and layout transitions.
- Non-inverted AI chat mode with bottom alignment, streaming-aware auto-follow, and bidirectional pagination callbacks.
- Typed `sections` mode powered by `SectionList` with configurable sticky headers.
- NativeWind `className` forwarding and headless card composition.
- Strict generic pagination and search hooks, reactive theming, AI discovery files, Jest coverage, and GitHub Actions CI.

### Changed

- Published package surface is now limited to compiled artifacts, README, license, and `llms.txt`.
- Runtime dependencies remain zero; React and React Native are peer dependencies.
